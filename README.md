# White/Blue AF1 Funnel Demo

A mobile-first static funnel landing page for a white and blue Air Force 1-style sneaker drop.

This project was built using the UI/UX guidance from the `ui-ux-pro-max-skill` repo as design context, without installing Claude or any agent tooling.

## What is included

- `index.html` — one-page product funnel
- `styles.css` — responsive layout, visual system, animation rules
- `script.js` — scroll reveals and demo reservation feedback

## Design rules applied

- Mobile-first responsive layout
- Clear visual hierarchy and one primary CTA per screen
- 44px+ touch targets
- Visible focus states
- No emoji icons, SVG icons only
- Transform/opacity animation only
- Reduced-motion support
- No horizontal mobile scroll
- High-contrast CTA and readable typography
- Lightweight static files deployable on GitHub Pages, Vercel, Netlify, or any static host

## Important note

This is an independent design/demo funnel. It is not affiliated with Nike.
